# Students Performance - Statistical Analysis

## Project Overview
This project analyzes student performance using Python.

## Objectives
- Explore student performance data.
- Perform data cleaning.
- Calculate descriptive statistics.
- Visualize student scores.
- Conduct hypothesis testing.
- Analyze correlation between subjects.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Hypothesis Testing
1. Gender and Mathematics Scores
2. Test Preparation and Mathematics Scores
3. Mathematics and Reading Score Correlation

## Conclusion
This project uses statistical analysis and hypothesis testing to understand student academic performance.
